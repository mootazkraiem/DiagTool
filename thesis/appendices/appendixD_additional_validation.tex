\section{Identifiers with the most alerts}

Figure~\ref{fig:app-top-canids} ranks the eight identifiers with the most alerts after correction. Six of them (0x7EC, 0x7E4, 0x7BB, 0x7A8, 0x7B3 and 0x7A0) lie in the range 0x7A0 to 0x7EC, which the vehicle uses for \gls{uds} diagnostic requests and responses. This matches the way the recording was made, by active polling (Appendix~\ref{app:datasets}). The two others, 0x19, the identifier with the most alerts, and 0x13, are broadcast identifiers and not diagnostic ones; without a \gls{dbc} file for them, we cannot say which values they carry.

\section{Additional screenshots}

Figure~\ref{fig:screen-export-csv} shows the first rows of the \gls{csv} file exported from the Anomaly Intel screen after the analysis of the Jaguar I-PACE holdout recording. The figure is a rendering of the real file. Before the correction described in Chapter~\ref{chap:impl}, the scores were written with a decimal comma on a French Windows installation, which shifted the later columns. We read the file again with a standard \gls{csv} reader after the correction: its 339 rows all have the 9 columns of the header, and every score is read as a number.
