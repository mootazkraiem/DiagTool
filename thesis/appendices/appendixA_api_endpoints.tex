\chapter{REST API Endpoints}
\label{app:api}

Table~\ref{tab:api-endpoints} lists the \gls{rest} endpoints exposed by the backend, grouped by function. All endpoints are served on \texttt{http://127.0.0.1:8765} and consumed by the desktop client only.
